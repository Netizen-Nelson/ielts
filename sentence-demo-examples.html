Nelson IELTS — 元件示範

sentence-demo 語塊漸顯元件

讓雅思閱讀例句以語意語塊的方式，按節奏逐步呈現給考生。

示範 01
修飾語塊 + 簡單句

主角是 I，前後各有一個修飾性語塊。適合入門級練習。

Unlike health-conscious people, I don't mind having burgers for a meal, given the convenience.
示範 02
S + Vt + that 子句（雅思學術長句）

這是課程核心例句，主詞有長分詞片語修飾，受詞是 that 子句。共四個語塊。

Like their peers on rigid diets, athletes embracing flexible nutrition and regularly tracking macros report that this has had a more positive than negative impact on their overall performance.
示範 03
always-show 用法：骨架先顯，修飾語後揭示

用 always-show 讓句子骨架（S+V+O）一開始就亮著， 再逐步點亮修飾語塊，方向和示範二相反。

Recent studies published in peer-reviewed journals suggest that the adoption of sedentary lifestyles in developed countries has contributed significantly to rising rates of chronic disease particularly among young adults.
使用說明
HTML 語法
基本結構
<sentence-stage>
  <!-- 非語塊文字：直接放，一直顯示 -->
  I don't mind having burgers,

  <sentence-demo
    order="1"
    color="lavender"
    label="比較修飾語塊"
    note="Like + 名詞，提供對比背景。">
    unlike most people
  </sentence-demo>.
</sentence-stage>
always-show（骨架一直亮）
<sentence-demo always-show color="sky">suggest</sentence-demo>
全域設定（在載入 JS 後呼叫）
SentenceDemo.config({
  animMs:       320,          // 動畫毫秒
  defaultColor: 'lavender',  // 未指定 color 時的預設
  bgAlpha:      0.15,         // 語塊背景透明度
  dimOpacity:   '0.22',      // 未點亮時的透明度
  nextLabel:    '顯示下一個語塊',
  doneLabel:    '全部完成 ✓',
  resetLabel:   '重置',
});
<sentence-demo> 屬性
屬性 預設值 說明
order 0 顯示順序，從 1 開始。0 或省略表示一直顯示。
color lavender 顏色名稱，見下方色票。
label （空） 語塊的語意標籤，點亮後顯示在說明面板左側。
note （空） 點亮後顯示在說明面板的解析文字。
always-show — Boolean 屬性。讓這個語塊一直保持高亮，不參與逐步揭示。

擴充色票補足色相空缺：mint（冷藍綠）、coral（暖珊瑚橘）、periwinkle（藍紫過渡）、gold（暖金黃）、rose（飽和玫瑰粉）。 全部在深色背景下對比度 ≥ 4.5:1，WCAG AA 合格。
dim 文字色設定
SentenceDemo.config({
  dimColor: '#7a7e78',  // 未點亮語塊的文字色（預設）
                        // 對比度約 4.5:1，可讀但明顯低於點亮狀態
                        // 可調亮（如 '#9a9e98'）或調暗（如 '#585c56'）
});
